# 📖 About

IMAGEOC is a fast, lightweight, browser-based toolkit for editing images and PDFs without uploading files to any server.

Everything runs locally inside your browser, keeping your files completely private.

Inspired by tools like iLoveIMG and iLovePDF while focusing on simplicity, performance, privacy and modern UI.

IMAGEOC processes files **100% locally** inside your browser.

✅ No server uploads

✅ No account required

✅ No data collection

✅ Your files never leave your device
